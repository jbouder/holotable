<CardGrid>

## Safe by construction

<div class="home-safe">
  <div>
    <p>
      The model writes a <strong>spec</strong>, never the data. Every query it
      proposes, whether SQL, PromQL or LogQL, is parsed and checked before it
      runs, and again on every save: read-only, on the catalog allowlist, in a
      time window the server owns, under row and point limits, and behind each
      viewer's row filters. Connection details and credentials never leave the
      server.
    </p>
    <LinkCard
      title="The invariants"
      description="The rules every change to Holotable preserves, and where each is enforced."
      href="/architecture/invariants/"
    />
    <LinkCard
      title="How a panel executes"
      description="From a stored spec to a guarded SQL, PromQL or LogQL query."
      href="/concepts/executing-a-panel/"
    />
  </div>
  <div class="panel" aria-label="A query passing the guard">
    <div class="panel-head">
      <h3>Before it runs</h3>
      <span class="badge badge-live">Passed</span>
    </div>
    <pre class="guard-query"><span class="kw">SELECT</span> time_bucket(<span class="str">'1 minute'</span>, ts) <span class="kw">AS</span> t,
       route,
       percentile_cont(<span class="num">0.95</span>)
         <span class="kw">WITHIN GROUP</span> (<span class="kw">ORDER BY</span> latency_ms) <span class="kw">AS</span> p95
<span class="kw">FROM</span> http_requests
<span class="kw">GROUP BY</span> t, route
<span class="kw">ORDER BY</span> t</pre>

## Try it in one command

<p class="lede">A demo database, live sample metrics and ready-made dashboards, with no account to create.</p>

```sh
docker run -p 3000:3000 ghcr.io/jbouder/holotable:quickstart
```

Open `http://localhost:3000`. Upload a CSV, JSON or Excel file of your own and,
when its columns fit, get a starter dashboard built from them before you
configure a model. [Quick start](/getting-started/quick-start/)
