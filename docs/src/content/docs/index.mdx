## From a sentence to a live dashboard

<ol class="home-steps">
  <li>
    <strong>Describe it</strong>
    <span>“p95 latency by route for the last hour, red past 300 ms.”
    Holotable reads your source's catalog, so the model writes against your
    real tables and columns.</span>
  </li>
  <li>
    <strong>Refine it</strong>
    <span>Ask for changes in the same chat — “make the third one a bar chart” —
    or edit any panel's SQL, layout and thresholds by hand. Every save is a
    version you can diff and restore.</span>
  </li>
  <li>
    <strong>Watch it live</strong>
    <span>Panels stream fresh rows over one connection, each on its own
    refresh cadence, with a shared time picker, variables and annotations
    across the whole dashboard.</span>
  </li>
</ol>

## Safe by construction

The model writes a **spec**, never the data. Every query it proposes is parsed
and checked — SELECT-only, catalog allowlist, server-owned time window, row
limits, and per-viewer row filters — before it runs, and again on every save.
Connection details and credentials never leave the server.

## Try it in one command

```sh
docker run -p 3000:3000 ghcr.io/jbouder/holotable:quickstart
```

Open `http://localhost:3000`: a demo database, live sample
metrics and a ready-made dashboard, with no account to create.
